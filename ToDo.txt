Esempi del middleware dei ruoli:

Route::middleware(['auth'])->group(function () {

    // SOLO ADMIN
    Route::middleware(['role:admin'])->group(function () {
        Route::get('/admin/dashboard', function () {
            return 'Admin dashboard';
        });
    });

    // ADMIN + MANAGER
    Route::middleware(['role:admin,manager'])->group(function () {
        Route::get('/backoffice', function () {
            return 'Backoffice area';
        });
    });

    // SOLO CUSTOMER (area utenti)
    Route::middleware(['role:customer'])->group(function () {
        Route::get('/account', function () {
            return 'User account';
        });
    });

});

Roles
 ├── Role (admin / manager / customer / future roles)
 └── UserRole (pivot)
        ├── user_id
        ├── role_id
        ├── timestamps

User
 ├── UserInfo
 ├── Company
 ├── Addresses (N)
 ├── Emails (N)
 ├── Phones (N)
 └── Roles (N via pivot)
        └── Role (N)

User
 ├── CustomerProfile (personal)
 ├── CustomerProfile (work / business)


User (obbligatorio)
 ├── UserInfo (opzionale ma 1 max)
 ├── Company (opzionale, 0..1)
 ├── CustomerProfiles (1..N) -- viene creato al primo evento utile, non subito al signup
 ├── Addresses (0..N)
 ├── Emails (0..N)
 └── Phones (0..N)


SIGNIFICATO DEL MODELLO:

✔ User
identità login

✔ UserInfo
profilo anagrafico esteso (non business-critical)

✔ Company
solo se utente è business

✔ CustomerProfiles (CORE DEL SISTEMA)

    contesto acquisto
