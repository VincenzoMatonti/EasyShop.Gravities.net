# Roadmap

## Introduction

EasyShop is an evolving ecommerce platform built with an enterprise-oriented architecture.

The roadmap follows the expansion of business capabilities while maintaining the existing technical structure.

---

# Completed

## Foundation

- Laravel project setup
- Authentication system
- Database foundation
- Initial application structure

## Identity

- User management foundation
- Role system
- Authorization middleware

## Customer

- Customer profiles
- Personal dashboard
- Address management
- Customer authorization flow

## Commerce Core

- Catalog domain
- Product management
- Inventory foundation
- Cart foundation
- Orders foundation

## Infrastructure

- Mail service
- Redis integration
- Queue workers
- Jobs
- Events
- Listeners
- Exception management

## Architecture

- Technical Layered Architecture
- Domain-oriented organization
- Query and ViewModel refactoring
